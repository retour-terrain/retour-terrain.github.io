# Fiche programme patient

Formulaire statique (une seule page HTML, sans serveur ni stockage) pour préparer un programme d'exercices : le patient remplit la partie 1, le kiné la partie 2, puis le kiné partage la fiche.

Les informations saisies restent dans le navigateur de l'appareil et ne sont transmises que lorsque l'utilisateur partage ou copie la fiche.
